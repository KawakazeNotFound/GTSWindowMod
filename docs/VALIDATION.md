# 验证边界与验收清单

## 自动检查

GTSWindowMod 1.0.0 使用公共 NuGet 引用，Release 构建目标为 .NET Framework 4.7.2。依赖锁文件记录包版本与内容哈希；发布工作流使用 locked mode。

- 30 项窗口状态机/几何检查。
- 32 项合成游戏菜单与反射适配检查。
- 23 项自建隐藏 Win32 窗口检查：尺寸约束、工作区、边框、菜单路由、无额外子窗口、接管释放、清理。
- 8 项 Windows CLR 下的真实 Harmony 合成 Patch/Unpatch 检查。
- 打包验证：精确文件白名单、重复文件、全部文件 SHA-256、版本、提交信息、ZIP SHA-256。

隐藏窗口测试使用明确的 Unity Screen shim。Harmony 测试使用合成菜单对象和真实 HarmonyX，并非运行 Unity。测试不会启动游戏、操作其他应用窗口或写入真实游戏配置。

自动检查不证明游戏的独占全屏建立成功、画面或鼠标命中正确。运行时仍需验证确切图形设置绑定；游戏更新后的未知接口报告 UNKNOWN 并暂停增强。

## 游戏验收

1. 启动日志：GTSWindowMod 1.0.0、validated native graphics integration、本进程 UnityWndClass 绑定；游戏已是原生全屏时不抢回窗口。
2. 原生窗口：最大化、还原、最小化、双击/拖动标题栏，后台不反复抢回最大化状态。
3. 自由缩放：四边/四角、宽窄窗口、4:3/16:9；画面刷新、菜单、字幕及鼠标点击位置同步。
4. 最小客户区：640×360 默认约束；subclass 失败降级日志单独记录。
5. 无边框：铺满当前显示器且无额外按钮；通过游戏设置切回 Windowed 恢复标题栏。
6. 持久化：移动缩放后等待两秒，重启恢复；最大化/全屏不覆盖正常窗口矩形。
7. 多屏与 DPI：非主屏、负坐标显示器、混合缩放、拔插屏幕，检查工作区与恢复位置。
8. 任务栏：不同方向、自动隐藏；原生最大化遵循 Windows 工作区。
9. 接管 UI：仅分辨率/Try Resolution 灰显并标记；Window Mode 可选，画质/VSync/FOV/保存/取消正常。
10. 原生 Fullscreen：选择后恢复原生分辨率控件并应用；记录独占全屏、刷新率、Alt-Tab、多屏行为，等待后不被强制拉回窗口。
11. 重新接管：Fullscreen → Windowed/Borderless 并应用，拖边/最大化/无边框恢复，普通窗口矩形保留。
12. 取消预览与画质保存：取消 Fullscreen 预览保持原状态；仅改画质不触发额外窗口切换。
13. 卸载：关闭游戏移除插件，其他插件和游戏原始 DLL 保持原样。

每个 Release 的构建提交和 CI 运行信息位于 BUILD_INFO.json。构建、加载、消息命中、真实画面和输入验收分别记录，避免跨级推断。
